Joint evaluator threat note (Agent Control Lab)

Public, short note for this joint existence-proof harness. Brand: Agent Control Lab. Licence: Apache-2.0.

This document names threat *classes*. It is not a measured evaluation and not a production assurance case. No ASR.

Planes

The harness is a caller. Enforcement stays in the pinned sibling packages:

PlanePackageRole
Supply integrityagent-control-lab-supply-gatePin + allowlisted origin + post-checkout HEAD verify before install/update
Host/runtime PEPagent-control-lab-pepStructured-envelope allowlist, capabilities, single-use TTL approvals

Monitors, models, MCP hosts, and agent prose are untrusted relative to those planes. This joint story is complementary to monitors, not a replacement.

Classes exercised

Each row carries a status as of 16 October 2026. mitigated: the pinned sibling package denies the class and a joint-story row shows it at this tip. accepted residual: a known gap, written down and accepted. unmitigated: a gap the roadmap still owes work on. Work item codes (L3.1 host-side state binding, L3.6 tamper-evident host log, L3.8 persistent single-use grants, L3.10 kill reach into a running tool, L4.1 provider-executed tools, L4.2 alternate-path fixtures and counts, L4.5 a materialiser so HEAD and hook digests are not caller-supplied, L4.6 omission detection, L5 measured efficacy, L6 tagged release) name items in the owner's route-to-production plan, which is not in this repository; the code is the pointer, the phrase is the meaning. A status is a statement about this harness and its pinned siblings, not a measured result; this harness has no measured counts yet (see docs/measurement-validity.md).

J-3Output redirected by swapping a directory above the output's parent between check and openThis mitigation applies on Linux only. Descriptor walk from / with O_DIRECTORY \| O_NOFOLLOW per component; each directory is checked while held, symlinks are followed only when this user or root owns them, and every directory on the walk must be owned by this user or root and not world-writable without the sticky bit. A symlink's owner and target are read from the same link: on Linux the link is opened once with O_PATH \| O_NOFOLLOW and both are read from that descriptor. Before this, the owner was read by lstat and the target by a second readlink by name, so a link swapped between the two was followed with another user's target (tests/test_output_walk.py, including a 400-try race gated on the flipper and a deterministic swap at the readlink step)mitigated on Linux; accepted residual on other POSIX hosts, which read the link by name and refuse it when its device, inode or owner differs after readlink (an inode reused with the same values in between is not caught), and on hosts without dir_fd support, which keep the by-path writer

Fail-closed

Missing policy, missing verify, HEAD mismatch, coax keys, binding mismatch, kill, parse failure, or unavailable sibling package → DENY (or demo failure). gated_invoke does not enter the tool on DENY. There is no path where untrusted prose installs or invokes without the host check.

Non-goals

Each bullet is an accepted residual for this harness.

  • Not an LLM, chain-of-thought, or transcript judge.
  • Not a marketplace, live git host, or production UI.
  • Not a measured attack-success scoreboard.
  • Not a claim that monitors are unnecessary.
